1 B: Vale tío, la cocina aquí. El baño allí. / 오케이 티오, 부엌 여기. 화장실 저기. / 초안의 'Mira, esta es...' 대신 20대 반말 'Vale tío'로 재작성 / cheerful / F: Vale tía, la cocina aquí. El baño allí.
2 A: ¡Qué mola! ¿Dónde está mi cuarto? / 와 멋지다! 내 방은 어디야? / '¡Qué bonita!'를 '¡Qué mola!'로 바꿔 구어로 재작성 / excited
3 B: Es pequeña pero tiene luz. / 작아, 근데 빛 있어. / 초안보다 더 짧게 줄여 구어화 / cheerful
4 A: Vale, mola. ¿Qué es esa caja? / 오케이 좋아. 저 상자는 뭐야? / 'Perfecto' 대신 'Vale, mola'로 재작성 / cheerful
5 B: Es la caja del gato. Es pequeño. / 고양이 상자야. 작고. / 관사 'la'와 'del' 넣어 초안과 다르게 재작성 / amused
6 A: ¿Tú tienes un gato? ¿Dónde está? / 너 고양이 있어? 어디 있어? / 초안에 'Tú' 넣고 어순 바꿔 완전히 재작성 / surprised
7 B: En tu cama está. Es su cuarto, vale. / 네 침대에 있어. 걔 방이야, 오케이. / 'Bueno…' 대신 'vale' 넣고 어순 바꿔 재작성 / flustered
8 A: Pues estoy listo. ¡Tú eres el jefe! / 그럼 나 준비됐어. 네가 대장이야! / 'compañero' 대신 'estoy listo'로 성수 일치 보여주며 재작성 / shy / F: Pues estoy lista. ¡Tú eres el jefe!
추천 표현: vale / 오케이·알겠어 , mola / 멋지다·좋아
