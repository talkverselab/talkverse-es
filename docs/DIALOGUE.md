# 회화(다이얼로그) — 스페인어 특이점

**공통 원칙은 https://talkverse.uk/talkverse/dialogue-rules/ 를 따른다**(2026-11-02 확정 — 레벨 = 절벽 R1~R4, 턴 수, 한글 독음 필수, 설명 한국어, 반전 1회, 수위 12+, 변이 별도 파일, 검수 = 자동 검사 + 교차 검수).
절벽 기준표: https://talkverse.uk/cliff/18/ . 아래는 스페인어에만 해당하는 것만 적는다.

## 기본 변이
- 기본 = **스페인 카스티야(es_ES)**, 2인칭 복수 **vosotros** 사용. 중남미(ustedes·seseo 등)는 공통 원칙대로 **별도 파일**.
- 음성: es-ES 남·여 목소리(현재 AlvaroNeural / ElviraNeural).

## 성별판 규칙
- 형용사·과거분사가 **말하는 사람·듣는 사람의 성에 일치**한다(encantado/encantada, cansado/cansada, ¿estás lista?). 등장인물 성별을 바꾸면 이 부분을 같이 바꾼다 — 대사 칸 `note` 에 성 일치 지점을 표시.
- 관사·명사 성(el/la)은 앱의 성 색(남 파랑 / 여 빨강)과 맞춘다.

## 턴 길이 (공통 턴 수 안에서)
- R1: 한 턴 **8단어 이하**(지금 샘플 평균 5.6, 최대 9). R2: 12단어 이하. R3·R4: 문장 2개까지.
- 역부호 ¡ ¿ 는 항상 쓴다.

## 한글 독음 표기표 (`rd` 칸, 초안 — 공통 원칙의 「독음 필수」용)
| 철자 | 독음 | 예 |
|---|---|---|
| j, g(+e·i) | ㅎ | jamón 하몬, gente 헨떼 |
| c(+e·i), z | ㅆ(카스티야 θ) | gracias 그라씨아스, zapato 싸빠또 |
| ll, y(모음 앞) | ㅇ·ㅈ 사이 → ㅇ+반모음(야·요) | llamo 야모, yo 요 |
| ñ | 니+모음 | España 에스빠냐 |
| r(어두)·rr | ㄹㄹ | perro 뻬로, rojo 로호 |
| p·t·c(k) | 된소리 ㅃ·ㄸ·ㄲ | pan 빤, tú 뚜, casa 까사 |
| h | 소리 없음 | hola 올라 |
| 강세 | 표시 안 함(철자 á é í ó ú 로 충분) | |

## 레벨 어휘 · 학습자 성별 (2026-11-07 초안 기준)
- 절벽 45·69·168·570 은 그 안의 단어만으로 회화를 쓰기엔 좁다. 회화 레벨은 **R1 = 주로 570위 안, R2 = 주로 1,000위 안, R3 = 주로 2,000위 안**, 장면 명사는 편당 1~3개 벗어나도 된다.
- A 의 말·A 를 부르는 말이 성으로 갈리면 기본 `tl` = 남성형, 그 턴에 `tl_f`·`rd_f`(여성형). 작성 규칙 전체는 `tools/prompts/dialogue_es.md`.
