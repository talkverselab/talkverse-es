# 스페인어 문법 요소 — 레벨 배치 (2026-11-08, 사용자 결정 반영)

레벨 = 문법 단계(굴절어 전략 A1): 0 소리·짧은 회화 · 1 관사·성수·활용 골격(10단계) · 2 챗 실전 · 3 그래머2(복수·존댓말) · 4 어려운 문법(10항목) · 5 어휘 완주.
「처음 보임」 = 통문장(외우는 덩어리)으로 처음 나오는 레벨, 「익힘」 = 규칙으로 가르치는 레벨. 「지금 초안」 = 58편에서 그 요소가 나온 편 수(spaCy 자동 집계, R0 8편·나머지 10편).
