# 스토어 설명·스크린샷 — 스페인어유니버스 (애플 지침 4.3 차별화, 2026-11-09)

기준 `~/talkverse/STORE_DIFFERENTIATION.md`(사용자 "엄청 중요해"). **출시는 Talkverse 통합 앱 하나**(com.talkverse.app) — 언어앱은 개별 출시하지 않는다. 이 문서는 통합 앱 스토어 설명의 스페인어 칸·통합 앱 심사 메모의 스페인어 문단·(혹시 단독으로 낼 때) 이 앱 설명의 원본이다. 숫자는 출시 직전 실제 앱 기준으로 다시 잰다(아래 「실측 숫자」 표의 「지금」 칸).

## 1. 첫 줄(그 언어의 가장 큰 벽 + 해법)
> 스페인어의 벽은 동사 하나가 주어마다 모양을 바꾸는 활용과 ser·estar 두 개의 「이다」 — 스페인어유니버스는 회화 속 동사를 누르면 원형·인칭·시제가 바로 보이고, 같은 동사가 yo·tú·él 로 되풀이되는 회화로 활용을 몸에 붙입니다.

## 2. 스페인어 전용 학습 도구(앱에 실제로 있는 것)
1. **동사 칩**: 회화 문장 아래 활용형 → 원형·인칭·시제 칩, 누르면 현재·단순과거 활용표(핵심 동사 30, 불규칙 색 구분). 「나」 탭에 「만난 동사 n/30」.
2. **알파벳과 발음(카스티야)**: 글자 27(ñ 포함)·겹글자 ch·ll·rr·qu·gu/gü·스페인 소리 θ(ce·ci·z)·x(j·ge·gi)·r↔rr·b=v·강세 — 41단위, 탭하면 자동 재생·IPA·조음 위치·모음 위치를 한국어 모음과 비교.
3. **레벨 = 문법 단계**: 관사·성수 일치 → ser/estar → 현재 활용 → gustar → 목적 대명사 → … → 단순과거(10단계), 그다음 챗 실전·복수/vosotros·usted·접속법. 같은 동사·형용사가 여러 인칭·성수로 되풀이되도록 쓴 회화.
4. **학습자 성별판**: 학습자가 여자면 cansada·lista·tía 처럼 말이 바뀐 대본과 음성(남/여 두 판).
5. **절벽 단어**: 스페인어권 영화·드라마 대사에서 잰 기본형 순위 — 45개가 대사의 55%, 570개가 80%. 20어 단원 타일, 회화에 나온 단어 추가.
6. 문장 단어를 누르면 단어창(뜻·품사·빈도·구간), 한글 독음은 기본 숨김(카스티야 θ = 「ㅆ」 등 자체 표기표).
